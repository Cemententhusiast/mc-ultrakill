# Beta 0.1

First early beta of UltraStyle for Minecraft Java 26.3 (Fabric).

**Limited playtesting: this is a prerelease, not a stable or broadly compatibility-tested build.** Expect bugs, visual issues and balance changes. Back up worlds before enabling gameplay-affecting features such as XP multiplication.

## Included

- ULTRAKILL-inspired perspective style sidebar with ranks, combos and action feedback.
- Rank-based XP multiplier (×1–×8) in single-player; enabled by default and toggleable with `/ultrastyle xp off`.
- Custom boss bars with damage trails.
- Boss-fight summaries with elapsed time, style, personal bests, peak rank and damage statistics.
- Life summaries replacing the death-screen artwork while retaining vanilla Respawn/Spectate and Title Screen controls.
- Configurable HUD positioning and depth angle, and saved personal-best scores.

## Install

Requires Minecraft Java **26.3**, Java **25**, Fabric Loader **0.20.1 or newer**, and Fabric API for Minecraft 26.3 (built against **0.165.2+26.3**).

Place `ultrastyle-0.1.0-beta.1.jar` in the client's `mods` folder alongside Fabric API. This is a client-only mod: do not install it on a dedicated server. No server installation is required for cosmetic multiplayer features.

## Known limitations

- Multiplayer score and kill attribution are best effort. Real XP multiplication works only for the local player on the integrated server.
- Multiplayer damage totals are unavailable and displayed as N/A.
- Life stats begin on joining or respawning; activity before the current client session is not reconstructed.
- Ender Dragon and Wither are recognized by default. Other bosses require configuration and may need custom integration.
- Hardcore, custom bosses, other HUD mods and a broad range of multiplayer servers have not been thoroughly playtested.
- Remote waterlogged block breaks may be omitted, and high latency can affect observations.
- Scores, multipliers and presentation are early balancing choices and may change.

## Validation

20 unit tests passed. An automated disposable-world test defeated a Wither, checked final-hit and death statistics, rendered both results panels, and exercised the vanilla Respawn button. These checks do not replace extensive manual playtesting.

See the repository README for configuration, commands and the full list of limitations.
